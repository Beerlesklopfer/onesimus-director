Removes temporary tables created during a BVFS restore session. Each `.bvfs_restore` call creates a temporary table identified by a handle (path); this command cleans it up after the restore job has been submitted or cancelled.

## Syntax

```
.bvfs_cleanup path=<handle>
```

## Arguments

| Argument | Description |
|----------|-------------|
| `path=<handle>` | The restore handle (temporary table identifier) returned by `.bvfs_restore`. |

## Examples

### Cleanup a specific restore handle
```
* .bvfs_cleanup path=b21234
BVFS cleanup for handle "b21234": done
```

### Cleanup after a completed restore workflow
```
* .bvfs_restore path=b29999 jobid=10 fileid=1,2,3
BVFS restore: path=b29999 jobid=10 fileid=1,2,3
* restore ...
* .bvfs_cleanup path=b29999
BVFS cleanup for handle "b29999": done
```

### Cleanup with WebUI-style handle
```
* .bvfs_cleanup path=b2163845
BVFS cleanup for handle "b2163845": done
```

## Notes

- The handle is typically a string like `b2NNNN` generated by the client (WebUI or bconsole).
- If the handle does not exist (already cleaned up or never created), the command succeeds silently.
- Temporary tables consume catalog database space; always clean up after restore sessions.
- The WebUI calls this automatically when the restore dialog is closed.
